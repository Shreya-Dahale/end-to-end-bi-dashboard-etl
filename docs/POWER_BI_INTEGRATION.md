# Power BI Integration Guide

This guide describes how to connect Microsoft Power BI Desktop to the cleaned dataset generated by this ETL pipeline.

## 1. Fast Direct CSV Import (Recommended)

1. Launch **Microsoft Power BI Desktop**.
2. On the **Home** tab, click **Get Data** -> **Text/CSV**.
3. Navigate to your project directory and select:
   ```
   end-to-end-bi-dashboard-etl\data\cleaned_superstore.csv
   ```
4. In the preview window, confirm that data types and UTF-8 encoding are correctly identified.
5. Click **Load**.

## 2. Direct SQLite Database ODBC Connection

To connect Power BI live to the underlying SQLite database (`database/superstore_bi.db`):

1. **Install SQLite ODBC Driver:**
   - Download and install the 64-bit SQLite ODBC driver from: [http://www.ch-werner.de/sqliteodbc/](http://www.ch-werner.de/sqliteodbc/)
2. **Open Power BI Desktop:**
   - Click **Get Data** -> **More...** -> **Other** -> **ODBC**.
   - Click **Connect**.
3. **Configure Connection:**
   - In **Data source name (DSN)**, leave blank or select your DSN.
   - Expand **Advanced options**, and enter the Connection String:
     ```
     Driver={SQLite3 ODBC Driver};Database=C:\Users\HOME-LAP\.gemini\antigravity\scratch\end-to-end-bi-dashboard-etl\database\superstore_bi.db;
     ```
   - In SQL statement, you can query directly:
     ```sql
     SELECT * FROM orders;
     ```
4. Click **OK**, select Windows/Default credentials, and load your table.

## 3. Recommended DAX Measures

Add these key DAX measures to your Power BI report:

```dax
// 1. Total Revenue
Total Sales = SUM(orders[Sales])

// 2. Total Net Profit
Total Profit = SUM(orders[Profit])

// 3. Overall Profit Margin %
Profit Margin % = 
DIVIDE(
    [Total Profit],
    [Total Sales],
    0
)

// 4. Total Order Volume
Total Orders = DISTINCTCOUNT(orders[Order ID])

// 5. Total Units Sold
Total Quantity = SUM(orders[Quantity])

// 6. Average Order Value (AOV)
Average Order Value = 
DIVIDE(
    [Total Sales],
    [Total Orders],
    0
)

// 7. Year-over-Year (YoY) Sales Growth
Sales YoY Growth % = 
VAR CurrentSales = [Total Sales]
VAR PreviousYearSales = CALCULATE([Total Sales], SAMEPERIODLASTYEAR(orders[Order Date]))
RETURN
DIVIDE(CurrentSales - PreviousYearSales, PreviousYearSales, 0)
```

## 4. Suggested Report Layout in Power BI
- **Top Row Cards:** Total Sales, Total Profit, Profit Margin %, Total Orders.
- **Main Chart 1:** Line and Clustered Column Chart (Shared Axis: `Year-Month`, Column: `Total Sales`, Line: `Total Profit`).
- **Main Chart 2:** Treemap of `Category` and `Sub-Category` by `Total Sales`.
- **Map:** US State Map filled by `Total Sales` with Tooltip of `Profit Margin %`.
- **Slicers:** Date Slider (`Order Date`), Region Slicer, Segment Slicer.
